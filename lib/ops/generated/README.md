# Generated OPS types

The official OpenAPI file is referenced by OPS as `docs/openapi/website-integration-v1.json`, but it is not present in this repository and was not available in the supplied project archive.

Do not create guessed generated types. Check the exact OpenAPI JSON into `docs/openapi/website-integration-v1.json`, then generate this directory atomically with the OPS runtime/docs revision. Until then, `lib/website/publicContractContract.ts` is the strict runtime adapter and fails closed on unsupported canonical data.
